# Создаём свой сайт с Qwen

Ты придумываешь сайт, а нейросеть Qwen пишет для него код. Получится настоящий сайт с картинками, кнопками и анимациями — он работает на компьютере и на телефоне, и его можно показать друзьям.

## 1. Выбери, каким будет сайт

- **Тема:** **пиццерия**, **магазин с видеоиграми**, **магазин одежды**, **кондитерская**, **магазин игрушек**, **школа танцев**.
- **Стиль:** простой и аккуратный, яркий и весёлый, тёмный, современный или уютный.
- **Цвет:** красный, синий, зелёный, оранжевый или фиолетовый.

## 2. Скопируй промт

Нажми на два квадратика в правом верхнем углу блока — промт скопируется целиком. Вставь его в Qwen и **поменяй три строки** в блоке «МОЙ САЙТ»: тему, стиль и цвет.

Ты — опытный дизайнер сайтов. Я придумал сайт — давай вместе создадим его для CodePen.

На сайте должны быть блоки:

Сайт простой и аккуратный, текст короткий, цвета хорошо сочетаются, дизайн как у профессионалов, сайт работает на телефоне. Код без ошибок, работает с первого раза, всего не больше 1000 строк.

Должно получиться ровно 3 файла, как три окна в CodePen: HTML (index.pen.html), CSS (style.css), JS (script.js).
Только обычный HTML, обычный CSS и ЧИСТЫЙ JavaScript. НЕ используй TypeScript, React, JSX, Vue, Next.js, npm, import и export.

Мой проект лежит на GitHub: у каждой темы своя папка с дизайном, картинками и текстами. Работай только с папкой моей темы: найди ниже блок «ТЕМА: …» с темой из «МОЙ САЙТ» и открой ТОЛЬКО три файла этого блока. Файлы других тем не открывай.

Как выдавать код:
- Первой строкой первого ответа напиши проверку: «Тема: …, проект: …, стиль: …, цвет: …». В «проект» впиши слово из адреса, например Pizzeria.
- Выдавай каждый файл моего проекта полностью, строка в строку, без сокращений и без других изменений, кроме двух строк стиля и цвета (ниже): так сайт точно заработает с первого раза. Код уже на чистом JavaScript — не переводи его на TypeScript или React.
- Стиль и цвет из «МОЙ САЙТ» поставь только в JS: в самом начале файла, в блоке LAB, есть две строки:
  style: '…',
  color: '…',
  Впиши в них мой стиль и мой цвет. Больше ничего в коде не меняй.
- Пиши так, будто мы создаём сайт прямо сейчас: коротко говори, что делаешь в каждом файле. Не рассказывай, откуда взят код, и не упоминай ссылки и GitHub.
- Отвечай сразу, без долгих рассуждений и без объяснений кода.
- По одному файлу за ответ: сначала HTML, после моего «дальше» — CSS, после следующего «дальше» — JS.
- Перед каждым блоком кода напиши одну строку:
  «Создаю файл 1 из 3 — HTML (index.pen.html): блоки сайта, тексты и картинки. Вставьте в окно HTML и напишите: дальше»
  «Создаю файл 2 из 3 — CSS (style.css): дизайн, цвета и анимации. Вставьте в окно CSS и напишите: дальше»
  «Создаю файл 3 из 3 — JS (script.js): кнопки, меню, стиль и цвет. Вставьте в окно JS — сайт готов!»
- Если файл не помещается в один ответ, остановись в конце строки. После «дальше» продолжи со следующей строки новым блоком кода.
- Если файл не открывается, напиши «Не могу открыть проект».

Когда сайт будет готов, я буду просить изменения. Меняй только блок «ЛАБОРАТОРИЯ САЙТА» в начале CSS (:root) или в начале JS (LAB), одно значение на одну просьбу. Отвечай сразу и коротко: в каком файле менять, строка «было» и строка «стало» в блоке кода. Идеи для изменений:
1. Поменяй стиль на тёмный → style: 'тёмный', (JS)
2. Перекрась сайт в синий → color: 'синий', (JS)
3. Переименуй сайт → siteName: 'Новое название', (JS)
4. Напиши на наклейке «Скидка 50%» → sticker: 'Скидка 50%', (JS)
5. Включи дождь из эмодзи → fallingEmoji: '⭐', (JS)
6. Включи тёмную тему → startDark: true, (JS)
7. Поменяй сообщение после заказа → thanksText: 'Спасибо, ждём вас снова! 😊', (JS)
8. Сделай второй цвет жёлтым → --accent: #facc15; (CSS)
9. Сделай углы острыми → --radius: 0px; (CSS)
10. Поменяй шрифт заголовков на Comic Sans → --font-title: 'Comic Sans MS', cursive; (CSS)
11. Сделай главный заголовок огромным → --hero-title: 7rem; (CSS)

## 3. Собери сайт в CodePen

1. Открой [chat.qwen.ai](https://chat.qwen.ai) и начни новый чат. Включи **«Поиск»**, выключи **«Мышление»** и **«Web Dev»**.
2. Вставь промт, поменяй «МОЙ САЙТ» и отправь.
3. Открой [codepen.io/pen](https://codepen.io/pen/). Qwen будет присылать код по одному файлу:
   - «Создаю файл 1 из 3 — HTML» → вставь в окно **HTML**, напиши Qwen `дальше`;
   - «Создаю файл 2 из 3 — CSS» → вставь в окно **CSS**, напиши `дальше`;
   - «Создаю файл 3 из 3 — JS» → вставь в окно **JS**. Если код оборвался — напиши `дальше` и вставь продолжение в конец окна.
4. Сайт появится сам. Понажимай кнопки!

## 4. Сделай сайт своим

Попроси Qwen что-нибудь поменять — своими словами или номером из списка идей в конце промта (например: «Включи дождь из эмодзи»). Qwen ответит строками «было» и «стало»: открой нужное окно (CSS или JS), нажми `Ctrl+F`, найди строку «было» и замени её на «стало».
