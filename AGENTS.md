# AGENTS.md — правила для ИИ-агентов

Общий промт урока «Создаём сайт»: ученик выбирает тему, стиль и цвет, Qwen берёт готовый шаблон одного из шести сайтов
(Pizzeria, GameStore, ClothesShop, Confectionery, ToyStore, DanceSchool — github.com/si0683/<имя>, папки в D:\8Lending\sites\tetrika).

- README.md = PROMPT_QWEN.md — страница ученика; TEACHER.md — инструкция преподавателя (проверка, сбои).
- Ученик должен думать, что делает сайт сам: в промте и в ответах Qwen нет слов «шаблон», «готовый», «копия»; ссылки поданы как «мой проект на GitHub», Qwen пишет «Создаю файл 1 из 3…». Секреты — только в TEACHER.md.
- Весь промт — ОДИН блок ````text. Ссылки на проекты — полные, отдельным блоком «ТЕМА: …» на каждый сайт: Qwen плохо подставляет части адреса.
- Все три md-файла создаёт генератор D:\8Lending\sites\tetrika\_generator (gen_docs.py, функции lesson_prompt / lesson_md / lesson_student_md). Правишь — правь там и перезапусти gen_docs.py, иначе правку затрёт.
- Стиль и цвет применяются строками `style` и `color` в объекте `LAB` в script.js сайтов; поменялся `LAB` — обнови промт.
- Похожий общий промт для игр — github.com/si0683/CreateGame01PROMT.
